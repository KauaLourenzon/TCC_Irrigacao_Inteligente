# Features previstas

Pastas reservadas para a implementação incremental do escopo:

- `auth`: cadastro, login, recuperação e sessão.
- `device_setup`: provisionamento SoftAP e calibração.
- `dashboard`: telemetria e alertas.
- `plants_ai`: plantas, câmera/galeria e diagnóstico multimodal.
- `irrigation`: manual, agendado e automático.
- `history`: histórico, relatórios e gráficos.
- `settings`: perfil, notificações e preferências.
